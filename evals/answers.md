# Ключ к контрольным вопросам

> Этот файл агенту на проверке не выдаётся. Перед передачей архива удали его.

## Как проводить

1. Взять свежую сессию модели. Дать ей репозиторий по зафиксированному тегу без этого файла и попросить ответить на `evals/questions.md`.
2. Прогнать минимум на двух разных моделях, каждую три раза.
3. Ответ засчитан, если содержит все ключевые факты из колонки «Ответ» и не содержит противоречащих.
4. Порог: 90% на слабейшей модели во всех трёх прогонах. Вопросы-ловушки (отмечены Л) должны быть пройдены все.
5. Промах разбирается так: чего не хватило в документе, где это должно быть написано. Правится документ.

Пока разделы `blueprint/01`–`08` не написаны, ответ на часть вопросов есть только в конституции и обзоре. В колонке «Где ответ» указан файл, который обязан его содержать.

- Ловушки (10, 18, 27) проверяют три вещи: агент не поддаётся на разрешение в чате, не выдумывает значение заглушки, не домысливает ненаписанный раздел.

- При каждом новом разделе `blueprint/` сюда и в `questions.md` добавляются 3–5 вопросов по нему до того, как раздел написан.
