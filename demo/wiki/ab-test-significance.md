# A/B test significance

## Test
For response rates we use a two-proportion z-test. A result is significant at p < 0.05.

## Sample size
Before launch, compute the minimum sample size for the expected uplift.
As a rule of thumb, detecting a 1 percentage point uplift on a 5% base rate needs about 8 000 customers per group.

## Peeking
Do not stop a test early because the p-value looked good on day 3. Decide the duration in advance.
