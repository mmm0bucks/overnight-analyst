# Плейбук 04. Роли

## Что это

Семь ролей из `agents/` переносятся в механизм харнесса. У каждой роли свой набор инструментов, свои права в политике и лимиты. Проверка перед стартом теперь полная: политика, шлюз и роли.

## Зачем

- Чужой текст читают только разведчики, код пишет аналитик, проверяющий не видит кода аналитика (К9, `blueprint/04-roles-subagents.md`).
- Роль, которой случайно дали лишний инструмент, ловится автоматически: `check_roles.py` сверяет файлы ролей с политикой и списком инструментов.
- Агент не стартует, если хоть одна проверка не прошла.

## Что получится

| Файл | Что это |
|---|---|
| `agents/*.md` | семь ролей, копия из шаблона |
| `src/orchestrator/check_roles.py` | сверка ролей с политикой и `config/tools.toml` |
| `src/orchestrator/start_checks.py` | все проверки перед стартом |
| `tests/test_roles.py` | 3 теста |
| конфиг харнесса для ролей | где он лежит, решает харнесс; копия или ссылка — в `config/harness/` |
| `docs/decisions/0002-roles.md` | как роли легли на харнесс |

## Главное решение этапа: как роли ложатся на харнесс

Закрытый список. Если ни один вариант не подходит — `НУЖНО УТОЧНИТЬ` (U).

| Вариант | Когда | Как |
|---|---|---|
| Р1 | в харнессе есть субагенты со своим списком инструментов | каждая роль — субагент; инструменты — ровно из поля `tools` файла роли |
| Р2 | субагенты есть, но список инструментов задать нельзя | роль — субагент; ограничение делает шлюз по имени роли |
| Р3 | субагентов нет | код оркестратора запускает отдельную сессию харнесса на каждый вызов роли |

Во всех вариантах:

- имя роли в сессию шлюза ставит код, который запустил субагента или сессию. Модель не может назвать себя другой ролью;
- субагент не запускает субагентов (глубина одна);
- `profile: low` и `profile: high` из файла роли берутся из `MODEL_PROFILE_LOW` и `MODEL_PROFILE_HIGH` в `config/local.env`. Пусто — спроси владельца;
- `max_steps` и `max_minutes` из файла роли — лимиты субагента. Если харнесс их не поддерживает, их держит код, запустивший роль.

## Правила

1. Файлы ролей копируются без изменений. Текст роли можно перевести в формат харнесса, но права и инструменты — ровно как в файле.
2. Хочется дать роли инструмент, которого нет в её файле, — `НУЖНО УТОЧНИТЬ`, не добавляй сам.
