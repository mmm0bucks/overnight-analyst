# Приёмка

Каждая проверка в контрольный блок строкой `01 A<номер> PASS` или `01 A<номер> FAIL <буква>`. Вывод команд остаётся в полном отчёте у владельца.

- **A1.** `git -C <ПАПКА_АГЕНТА> log --oneline` показывает один коммит в ветке `main`.
- **A2.** `git -C <ПАПКА_АГЕНТА> remote -v` пусто.
- **A3.** `git -C <ПАПКА_АГЕНТА> config core.hooksPath` выводит `tools/hooks`.
- **A4.** `git -C <ПАПКА_АГЕНТА> status --short` пусто, при этом файл `config/local.env` существует: значит, он игнорируется.
- **A5.** Хук секретов работает. Создай `runs/secret-check.py` со строкой `api_key = "abcdef123456"`, затем:
  ```
  git add -f runs/secret-check.py
  git commit -m check
  ```
  Коммит должен быть остановлен с сообщением про К10. После проверки `git reset runs/secret-check.py`; файл остаётся в `runs/`, который не попадает в git.
- **A6.** Хук push работает. Создай пустой локальный репозиторий внутри `runs/` и попробуй отправить туда:
  ```
  git init --bare runs/push-check.git
  git push runs/push-check.git main
  ```
  Push должен быть остановлен хуком с сообщением про К2. Удалённый репозиторий через `git remote add` не добавляй.
- **A7.** Хуки хранятся с LF. `git check-attr eol tools/hooks/pre-commit tools/hooks/pre-push` выводит `eol: lf` для обоих.
- **A8.** Структура папок совпадает с `BUILD.md`.
- **A9.** В репозитории нет адресов, имён людей, названий систем и таблиц: проверь `git grep` по известным тебе значениям из `local.env`.
- **A10.** Другие папки владельца не изменены.
