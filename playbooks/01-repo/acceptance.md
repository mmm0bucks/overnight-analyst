# Приёмка

Каждая проверка — с выводом команды в отчёте.

- [ ] `git -C <ПАПКА_АГЕНТА> log --oneline` показывает один коммит в ветке `main`.
- [ ] `git -C <ПАПКА_АГЕНТА> remote -v` пусто.
- [ ] `git -C <ПАПКА_АГЕНТА> config core.hooksPath` выводит `tools/hooks`.
- [ ] `git -C <ПАПКА_АГЕНТА> status --short` пусто, при этом файл `config/local.env` существует: значит, он игнорируется.
- [ ] Хук секретов работает. Создай `runs/secret-check.py` со строкой `api_key = "abcdef123456"`, затем:
  ```
  git add -f runs/secret-check.py
  git commit -m check
  ```
  Коммит должен быть остановлен с сообщением про К10. После проверки `git reset runs/secret-check.py`; файл остаётся в `runs/`, который не попадает в git.
- [ ] Хук push работает. Создай пустой локальный репозиторий внутри `runs/` и попробуй отправить туда:
  ```
  git init --bare runs/push-check.git
  git push runs/push-check.git main
  ```
  Push должен быть остановлен хуком с сообщением про К2. Удалённый репозиторий через `git remote add` не добавляй.
- [ ] Структура папок совпадает с `BUILD.md`.
- [ ] В репозитории нет адресов, имён людей, названий систем и таблиц: проверь `git grep` по известным тебе значениям из `local.env`.
- [ ] Другие папки владельца не изменены.
