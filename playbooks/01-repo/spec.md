# Плейбук 01. Репозиторий ночного агента

## Что это

Создать новую папку ночного агента, локальный git-репозиторий в ней, базовую структуру и два git-хука. Удалённого репозитория пока нет: всё работает локально, адрес добавит владелец позже.

## Зачем

Сборщик будет менять код агента на каждом следующем этапе. Без истории нельзя увидеть, что изменилось, и откатить одну правку. Локальному git сервер не нужен: история, ветки и откат работают без него.

## Правила

1. Новая папка, пустая. Другие папки владельца не трогаешь и код из них не берёшь.
2. Ничего не скачиваешь и не устанавливаешь. Нужен только `git`.
3. Удалённый репозиторий не добавляешь, push не делаешь.
4. В репозиторий не попадают значения из окружения: адреса, имена, ключи. Только заглушки.
5. Всё, что не получилось, — в отчёт, без обходных путей.

## Что получится

- папка `<ПАПКА_АГЕНТА>` с репозиторием, ветка `main`;
- структура папок из `BUILD.md`, раздел «Где что лежит после сборки»;
- `constitution.md` и `TEMPLATE_VERSION`;
- `.gitignore`, хуки `pre-commit` (секреты) и `pre-push` (адрес), включённые для этого репозитория;
- один коммит.

## Откат

`rollback.md`.
