# Приёмка аудита

Перед тем как отдать ответ владельцу, проверь каждый пункт.

- [ ] В системе ничего не изменено: нет новых и изменённых файлов кода, конфигов, политики, базы знаний.
- [ ] В кластере ничего не запускалось.
- [ ] В ответе есть все 12 разделов с исходными номерами.
- [ ] В разделе 11 есть строка для каждого правила К1–К17.
- [ ] В ответе нет: ключей, токенов, адресов, хостов, имён людей, названий систем, проектов, таблиц, схем, путей, цитат кода и промптов.
- [ ] Каждое утверждение основано на том, что ты проверил в файлах или конфигурации. Непроверенное помечено `не знаю`.
- [ ] Объём не больше трёх страниц.

Владелец перечитывает ответ сам, прежде чем выносить его из своего окружения.
