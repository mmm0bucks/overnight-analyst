# Архитектура

[English](architecture.md) · **Русский**

```
overnight run
  │
  ├─ preflight            всё ли на месте? доступна ли модель? → иначе публикуем заметку «failed»
  │
  ├─ этап collect         инструменты: трекер, вики, SQL на чтение  → runs/<id>/collect.json
  ├─ этап analyze         инструменты: вики, SQL на чтение          → runs/<id>/analyze.json
  ├─ этап synthesize      без инструментов, только переиспользует утверждения → runs/<id>/synthesize.json
  ├─ этап critique        без инструментов, проверяет отчёт         → runs/<id>/critique.json
  │      (у каждого этапа чистый контекст; лимиты проверяются перед каждым вызовом модели и инструмента)
  │
  ├─ finalize             детерминированные проверки               → runs/<id>/finalize.json
  │
  └─ publisher            ЕДИНСТВЕННЫЙ писатель vault/ и state/ (атомарно, с бэкапом, без секретов)
         ├─ vault/Overnight/Reports/<дата> <run_id>.md
         ├─ vault/Overnight/Hypotheses.md   (управляемый блок, ваш текст вокруг сохраняется)
         └─ state/hypotheses.json, state/runs.json
```

## Модули

| Модуль | За что отвечает |
|---|---|
| `orchestrator.py` | preflight, порядок этапов, изоляция сбоев, артефакты, журнал событий |
| `stages.py` | контракты ответов (pydantic), роли, разрешённые инструменты этапа |
| `agent.py` | бюджет и ограниченный цикл вызова инструментов для одного этапа, одна попытка исправить плохой JSON |
| `tools.py` | инструменты только на чтение; каждый вызов становится источником `S1, S2, ...` |
| `sqlguard.py` | лексическая проверка SQL (слой 1); DuckDB `read_only=True` — слой 2 |
| `gates.py` | источники, прослеживаемость чисел, синтез без новых фактов, вердикт критики |
| `publisher.py` | единственный писатель: атомарная запись, бэкапы, управляемые блоки, вычистка секретов |
| `llm.py` | HTTP-клиент для OpenAI-совместимого API с политикой повторов; скриптовый клиент для тестов |
| `offline.py` | детерминированная заглушка на правилах для CI и бесплатного демо (не LLM) |
| `demo_data.py` | синтетическая база с фиксированным seed и заложенными ошибками |

## Границы доверия

* Модель может только **читать**: инструментов записи нет. Пишет publisher — обычный код,
  после проверок.
* SQL — один запрос, только чтение, лимит строк и квота на этап; табличные функции, которые
  читают файлы, запрещены; само подключение открыто только на чтение.
* Прогон, не прошедший проверки, всё равно публикуется (чтобы человек его увидел), но
  помечается `partial` и **не меняет** список гипотез.
