# 0003 — Каждое число должно прослеживаться до результата инструмента

[English](0003-traceable-numbers.md) · **Русский**

**Статус:** принято

**Контекст.** LLM ненадёжны в арифметике и охотно выдают правдоподобные числа.

**Решение.** Каждый вызов инструмента регистрируется как источник `S<n>`. У утверждения
есть `sources` и необязательное число `value`. Проверка смотрит, что это число буквально
встречается в сырых результатах указанных источников; промпт требует считать через SQL, а
не в уме.

**Последствия.** Выдуманные или неверно посчитанные числа валят проверки прогона.
Производные числа должны приходить из запроса — заодно остаётся след для аудита.
