# 0001 — Детерминированный оркестратор вокруг этапов с LLM

[English](0001-deterministic-orchestrator.md) · **Русский**

**Статус:** принято

**Контекст.** Ночная задача без присмотра ломается скучно: нет сети на старте, этап
зависает, токены утекают, модель возвращает битый JSON или говорит «готово», когда это не
так. В свободном цикле агента нет надёжного места, чтобы всё это обработать.

**Решение.** Прогоном управляет обычный Python: preflight, порядок этапов, бюджеты,
таймауты, артефакты, проверки и публикация. Модель вызывается внутри узких этапов с жёстким
контрактом и возвращает данные, а не управление.

**Последствия.** Меньше «автономии» на вызов, зато прогоны гораздо предсказуемее. Упавший
этап переводит прогон в `partial`, а не губит всю ночь. Каждый этап оставляет артефакт,
поэтому сбой можно разобрать по файлам.
