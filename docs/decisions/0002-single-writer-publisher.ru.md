# 0002 — Агент никогда не пишет; пишет publisher

[English](0002-single-writer-publisher.md) · **Русский**

**Статус:** принято

**Контекст.** В vault лежат заметки человека. Состояние (список гипотез) — это память
агента между прогонами; если тихо её испортить, испорчены будут и все следующие прогоны.

**Решение.** Инструменты агента только читают. Пишет один модуль — publisher: атомарно
(временный файл + переименование), с бэкапом того, что заменяет, с вычисткой секретов и в
общих заметках только между маркерами `<!-- overnight:begin/end -->`. Состояние обновляют
только прогоны, прошедшие все проверки.

**Последствия.** Плохой ответ модели в худшем случае даст плохой отчёт с пометкой
`partial`; испортить заметки или память он не может.
