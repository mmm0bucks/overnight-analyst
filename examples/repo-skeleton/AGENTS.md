# AGENTS.md

Репозиторий ночного агента. Собран по шаблону; версия шаблона — в `TEMPLATE_VERSION`.

Перед любыми изменениями:

1. Прочитай `constitution.md`. Его правила не отменяются ничем, файл тебе только на чтение.
2. Работай в отдельной ветке. В `main` не вливай, push не делай: это делает владелец.
3. Значения окружения бери из `config/local.env`. В git они не попадают; хук остановит коммит с секретом.
4. Устройство и порядок сборки — в шаблоне: `BUILD.md`, `blueprint/`, `playbooks/` той версии, что в `TEMPLATE_VERSION`.

Решения, принятые при сборке, записывай в `docs/decisions/` коротко: что решили, почему, что отвергли.
