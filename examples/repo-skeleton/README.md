# Образец нового репозитория

Файлы, которые плейбук `01-repo` копирует в новый репозиторий ночного агента. Здесь они лежат, чтобы сборщик переносил их, а не писал заново.

| Файл | Куда копируется | Зачем |
|---|---|---|
| `dot-gitignore` | `.gitignore` | секреты, прогоны и выгрузки не попадают в git. Здесь он назван иначе, чтобы не действовать на этот репозиторий |
| `dot-gitattributes` | `.gitattributes` | хуки всегда с LF: с CRLF, который ставит git для Windows, они перестают запускаться |
| `AGENTS.md` | `AGENTS.md` | вход для сборщика в новом репозитории |
| `tools/hooks/pre-commit` | то же | останавливает коммит с секретом (К10) |
| `tools/hooks/pre-push` | то же | push только на адрес из `config/allowed_remote.txt` (К2) |
| `config/allowed_remote.txt` | то же | пустой: push запрещён, пока владелец не впишет адрес |
| `config/local.env.example` | то же | список переменных окружения без значений |

Хуки написаны на `sh`: они работают и в Linux, и в git для Windows. Проверены: коммит с `api_key = "..."` и коммит `local.env` останавливаются, push на адрес не из файла останавливается, на адрес из файла проходит.
